## Page 2 - Interaction loop

Text extracted:

```text
Agent interacts with world (receives email, text instructions, etc)

Agent uses context of interaction (email/text received) and context from brain and preset personality to propose action taken (send this email, enter info into CRM, etc)

Agent records key interaction info (company/contact info, action taken, revisions to action, etc) to the brain

Agent finds ways to improve process/workflow/etc
```

Interpretation:

- The loop is perceive -> propose -> act with approval where required -> record -> improve.
- The brain is not just memory. It is the source that lets each future action improve.
- Corrections from Brian are high-value training data and must be written back into durable workflow rules when repeated or material.
