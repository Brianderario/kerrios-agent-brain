**Kerri logo = "Dusk Coin"** (settled 2026-07-09 after several rejected rounds): a circle holding the photorealistic dusk sky from the kerrihq.com hero — 8-stop gradient (`#0A0A0B` → plum → rust → `#f2c56b`), blurred cloud light, warm glow low, faint stars, ONE teal star (`#6FD6CE`), thin cream rim. No drawn objects. **Brian's taste, learned the hard way: no illustrated/flat marks (rejected banded-sun twice as "cartoonish"), no script wordmarks (rejected 4 options). Photographic gradients + serif type = yes.** Wordmark: "Kerri" in Newsreader 600 cream, plain dotted i. Tagline in scene assets: "The operating company for B2B media" in JetBrains Mono teal. Favicon variant = full-bleed sky in rounded square (coin doesn't survive 16px). LinkedIn profile banner is scene-only, no wordmark. Rejected earlier same day: 8-point star + orbit rings, banded sun (flat cream, then gradient), script wordmarks (Mr Dafoe/Style Script/Great Vibes/Kaushan).

**Previous identities, retired:** the violet `#8161FF` star-tittle wordmark (June 2026, generated by `build.cjs`, kept in the repo for history) and the interim 8-point-star-with-orbit-rings mark that briefly shipped with the July 2026 redesign.

**Assets + reproducible build:** `~/Projects/kerri-brand/` (NOT a git repo). Run `node build-dusk.cjs` → regenerates `svg/dusk-*.svg`, `png/dusk-*.png` (mark 512, favicons 16/32/48/180, appicon 1024, lockup 1600, LinkedIn logo 800 + banner 1584×396 + cover 1128×191, og-image 1200×630), and `dusk-favicon.ico`. Fonts on disk: `Newsreader.ttf`, `JetBrainsMono-Medium.ttf`. Same toolchain as the old build: opentype.js + @resvg/resvg-js + png-to-ico.

**Live:** kerrihq.com header/footer (`#kerrimark` symbol in index.html, cream parts use currentColor), favicon set, icon.svg, og-image — deployed 2026-07-09 per [[kerrihq-website]]. LinkedIn set delivered to Brian same day (logo square, personal banner, company cover).

**Meaning (for writing about the brand):** the high desert is the niche markets the giants overlook; the banded sun on the horizon reads as rising on the new model; the teal horizon line is the system (Kerri) running underneath everything.
