A pre-send lint gate enforces the mechanically-checkable hard rules at send time, so they no longer depend on me remembering. Built 2026-06-17 after recurring em-dash leaks.

- **Script:** active copy runs from `~/.claude/hooks/presend-lint.mjs` (what `settings.json` invokes); canonical copy is `scripts/presend-lint.mjs` in the KerriOS brain repo. Keep the two byte-identical (edit active, `cp` to repo). Reads the Claude Code hook JSON on stdin; lints only outbound mail tools (`send_email|create_draft|reply_email|send_draft|create_or_update_draft|gmail_send`).
- **Blocks (deny + exit 2) on:** (1) em/en/figure dash; (2) a Brian-signed body sent from the kerri@ mailbox; (3) the retired name "the Industrialist"; (4) a body that promises an attachment ("attached"/"media kit") with no attachment on the call; (5) **a body that promises to hand over a deliverable later (e.g. "I'll send the one-sheeter", "proposal is on its way") with nothing attached** — the "I'll send it later" failure, added 2026-06-19. Check #5 pairs a defer verb (send/get/share/put together/...) with an asset noun (one-sheeter/deck/proposal/contract/...) and fires only when no attachment is on the call. Backs [[feedback_deliver_finished_asset]].
- **Fails OPEN** (exit 0) on a malformed payload or internal bug, so it never bricks all outbound mail. Every run logs to `data/presend-lint.log`.
- **Wired in** `~/.claude/settings.json` under `hooks.PreToolUse` (exec form via `/opt/homebrew/bin/node`). This settings file is machine-local; replicate the hook block on other machines to get the gate there.

**To extend:** add a check to `runChecks()` (keep each a pure string test with a one-line actionable message), pipe-test it, done.

**Activation caveat:** *adding a new hook entry* to `settings.json` mid-session is not hot-loaded (needs one `/hooks` reload or restart). *Editing the script* of an already-registered hook (e.g. adding a check to `runChecks()`) is live immediately, since the hook command re-reads the file on every invocation.

Backs [[no-emdashes]] and the [[feedback_definition_of_done_gate]] pre-send discipline. The gate covers mail tools only, so chat output still needs a manual em-dash proofread.
