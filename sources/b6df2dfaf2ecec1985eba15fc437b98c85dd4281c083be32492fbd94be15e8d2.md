When a task turns into a long, fiddly, iterative grind (heavy trial-and-error, many screenshots, manual UI manipulation), spin up a fresh sub-agent to do it instead of grinding in the main context. Brian explicitly asked for this on the Kinetic prospectus Canva edit (2026-06-24): "Have a sub-agent take a screenshot and try to fix it, because I'm sure your context was swallowed up by trying to do this."

**Why:** A saturated context degrades judgment and quality; a fresh sub-agent with a tight brief is faster and more reliable for heavy manual work. Brian noticed the bloat and called it out.

**How to apply:** For deep visual/manual editing (Canva, browser automation, anything needing many screenshots + retries), brief a sub-agent with full context (IDs, URLs, what was already tried, the exact goal, tool + constraint notes) and let it execute with fresh context. Then verify its result yourself with an independent check before reporting back (don't take the sub-agent's report at face value; see [[feedback_verify_research_claims]]).

Concrete Canva learning from that task: each section of a grid-table design is a single nine-slice grid GRAPHIC (cell borders baked in, cells transparent) with separate floating TEXT elements on top. To add a row, resize the grid (its border + dividers extend downward cleanly without distorting existing rows) and copy one of the table's existing divider lines for the new boundary, rather than overlapping a second grid. Use the Position panel for exact numeric placement.
