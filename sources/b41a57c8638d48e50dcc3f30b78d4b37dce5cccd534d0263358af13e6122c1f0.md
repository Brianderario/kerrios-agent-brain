Brian, 2026-06-19: "we should be implementing any style changes to routines as that's where most of our recurring work is done." Trigger: the new open-on-their-world cold opener was upgraded in the sales-writing playbook and demonstrated in a one-off 6/18 batch, but the scheduled `kerri-cold-outreach` routine was never flipped, so the 6/19 scheduled batch reverted to the old "I'm Kerri / we're a media company" opener. The change had been parked behind a "pending Brian's sign-off" gate inside the routine.

**Why:** Almost all outbound volume is produced by the scheduled routines (cold outreach, inbox-sweep replies + package quotes, pipeline/renewal follow-ups, the newsletter writers), not by interactive sessions. A style change that lives only in a playbook, a memory, or a single hand-run batch never reaches the recurring output. A one-off batch is not a routine change.

**How to apply:** When any writing/voice/craft rule changes, propagate it into every routine that drafts that kind of content in the SAME pass — edit the routine's `SKILL.md` (its actual drafting instructions), not just the reference doc. Don't park it behind a "pending sign-off" gate; if Brian approved the change, wire it in and verify the old instruction is gone. Send-authority routine files (`kerri-inbox-sweep`, `kerri-skill`, `kerri-skill/references/email.md`, `kerri-morning-brief`) can't be auto-committed, so they need an explicit reviewed edit in an interactive session — surface that and do it, never leave the style change un-wired there. Known open item (2026-06-19): the inbox sweep has good inline reply-voice rules but does not load the sales-writing playbook, so its package-quote/proposal craft (playbook Part B) + the 10-point pre-send rubric are not wired in.
