### Root cause of 2026-06-08 Graph-Brian outage (resolved)

Both custom Graph MCP servers originally pointed to the same `kerri-hardwarefyi-email-mcp/` directory. The `run-mcp.sh` script loads `.env` from its own dir and **overwrites** env vars passed by Claude Code's MCP config — so the `GRAPH_MAILBOX=brian@` in `.claude.json` was silently overridden by the `.env`'s `kerri@`.

**Fix:** created `~/.kerri-chief/brian-hardwarefyi-email-mcp/` with its own `.env` (`GRAPH_MAILBOX=brian@hardwarefyi.com`) and updated `.claude.json` to point there. Takes effect on next session start.
