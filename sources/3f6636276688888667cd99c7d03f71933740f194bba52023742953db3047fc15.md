**Kerri Console (approvals v1)** lives at `~/Projects/kerri-console/` and serves **http://localhost:4180** (always-on launchd agent `com.kerri.console`). Built 2026-06-11 at Brian's direction; he wants this to replace Google Tasks as his approval surface ("we are removing Google Tasks shortly in replacement of this").

- Reads the H/S/G approval queue **live** from Google Tasks using the kerri-gdocs OAuth creds (`~/.kerri-chief/kerri-gdocs-mcp/.env`).
- Full-page view per item: parsed context + the exact draft email; working APPROVE / EDIT-THEN-APPROVE / REDO-with-guidance / SKIP buttons that write back to the task. **It never sends email** — the inbox sweep still performs sends through its approval gate; console actions are equivalent to Brian editing/checking the task himself. Actions logged to `audit.log` + stamped in task notes (`...BY BRIAN VIA KERRI CONSOLE`).
- **Since 2026-06-11 the production Console is also the CRM SYSTEM OF RECORD** (Brian's brain↔console storage split, `brain/wiki/decisions/2026-06-11-brain-console-storage-split.md`): companies, contacts, and deals live in kerrihq-rails Postgres. Agents read/write via the V1 API (`/api/v1/companies?domain=…`, `/api/v1/people`) with `KERRIHQ_AGENT_API_KEY` from `~/.kerri-chief/secrets/kerrihq.env` (key name `kerri-agent-crm`; the older `KERRIHQ_SYNC_TOKEN` is tasks-only). `data/companies.json` is a read-only snapshot fallback; `brain/wiki/companies/` is frozen; the CRM Google Sheet gets a one-way mirror via `KerriOS/scripts/crm-sheet-mirror.mjs`.
- **Brian's primary approval surface is the PRODUCTION KMG Console: https://kerrihq-rails-xtua.onrender.com/organizations/c7ec4a59-c794-492a-aa61-d926ee8c61d1/tasks** (kerrihq-rails on Render). Its task review pages (shipped 2026-06-11) show the full draft + approve/edit/redo/skip; the local kerri-console server runs a 120s two-way sync (mirror queue out with full notes, execute web decisions against the source Google Task, applied_at stamped). When pointing Brian to pending approvals (briefs, texts, task alerts), reference the Render console URL, not Google Tasks.
- Rails KMG Console Phase 1 must port this experience ([[kerrihq-rails-dev-env]]); kerri-console is the spec. "Removing Google Tasks" means swapping the storage behind `/api/queue` + action endpoints — coordinate with the sweep contract before changing the store.
- **Since 2026-06-11 the Console also hosts the permissioned BRAIN layer** (kerrihq-rails `77e061e`, KerriOS port): knowledge records with provenance + candidate/canonical lifecycle, domain/sensitivity permission grants (Brian master, Ari finance/legal, Benji HWFYI/content, Zach S&W-only), source registry, agent scopes, ApprovalRequest proof trails, `brain:*`/`approvals:*` API scopes, and an idempotent KerriOS importer (Sources → KerriOS Brain → dry run/apply; local Mac only — the brain folder isn't on Render). Architecture: `kerrihq-rails/docs/brain-architecture.md`; decision: `brain/wiki/decisions/2026-06-11-console-brain-port.md`. Production needs a one-time `rails db:seed` on Render to create domains/grants/sources/agent scopes.
