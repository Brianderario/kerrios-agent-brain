Kinetic is KMG's hardware conference (Hardware FYI). The source of truth for its visual identity is the live site https://kinetic.hardwarefyi.com. The site is JS-rendered, so its design layer was captured from the live rendered DOM on 2026-06-17.

**Canonical home: Claude Design (claude.ai/design)**
When Brian says "Claude Design" he means Anthropic's product at https://claude.ai/design (chat + canvas; design-system imports; PPTX/Canva export), NOT the Canva connector. The Kinetic Blueprint lives there as a saved Design System:
- Name: "Kinetic Design System"
- Project URL: https://claude.ai/design/p/8b09724f-cf93-495b-8e40-e7ff0f09aeb6
- It is set as the active design system on the Claude Design home, so any new design (slides, one-pager, document, prototype) is generated on-brand against it.
- Contents generated by Opus 4.8 (grounded on the live site + the tokens below): tokens, components (Button, Badge, Tag, Card, Input), templates (sponsor-one-pager), slides (sponsor deck), ui_kits (event website screens), guidelines, assets, styles.css, plus a SKILL.md.
- To create collateral: open the project (or the Claude Design home with this system active) and describe what to make; export supports PPTX and Canva.

**Design tokens (exact values from the live site)**
- Base canvas background: #0E1115 (near-black). Dark mode is the default and primary look.
- Card / panel surfaces: #14181F and #2B303B
- Hairline borders: white at 10% opacity
- Signature accent, used ONLY for primary CTAs and small highlights, never as large fills: #8161FF (electric violet)
- Text primary: #FFFFFF; secondary / meta: #8F96A3 (muted cool gray)
- Headlines + button labels: JetBrains Mono, bold, UPPERCASE, tight negative letter-spacing
- Body copy: Inter
- Motifs: uppercase mono kicker labels like [ MAY 12-13 ] and Q-01, status badges (OPEN, LIMITED, SOLD OUT), countdown timer, tiered speaker/sponsor grids
- Tagline: Hardware has evolved. So has how it's built.
