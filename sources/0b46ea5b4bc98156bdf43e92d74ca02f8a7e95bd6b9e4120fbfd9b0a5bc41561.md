The Slack/AskSavant agents (Kerri + Oliver, see [[slack_agents_architecture]]) are **multi-model on Ollama** as of 2026-06-29 ([kerrihq-rails#202](https://github.com/kerrihq/kerrihq-rails/pull/202)). Cheap/fast models do grunt knowledge work; glm-5.2 stays the decision + code model.

**Tiers** (`AskSavant::ModelTiers`, every tier env-tunable, no code change needed):
- `fast` = `ASK_SAVANT_MODEL_FAST` (default `gpt-oss:120b`) — extraction, classification, summarizing; runs **context compaction**.
- `balanced` = `ASK_SAVANT_MODEL_BALANCED` (default `glm-4.7`) — context synthesis; runs **large-tool-result condensing**.
- `strong` = `ASK_SAVANT_MODEL_STRONG` (defaults to `ASK_SAVANT_MODEL`=`glm-5.2`) — the orchestrator loop: decisions + actions.
- `code` = `ASK_SAVANT_MODEL_CODE` (defaults to `glm-5.2`).
render.yaml pins fast/balanced on both web + worker. Tune by changing the Render env var + redeploy.

**Tool-result digestion**: large narrative tool outputs are condensed by the balanced tier before reaching glm-5.2's context. Env knobs: `ASK_SAVANT_DIGEST_TOOL_RESULTS` (default true), `ASK_SAVANT_DIGEST_THRESHOLD_CHARS` (12000), `ASK_SAVANT_DIGEST_TOOLS` (default `research_web,browser_run,read_mail_thread`). Excludes exact-data tools (deals/tasks/pricing/code/ids); fail-open; preserves names/numbers/money/dates/URLs/quotes verbatim.

**delegate_to_model tool**: the strong orchestrator offloads one bounded subtask (extract/classify/summarize/first-draft) to tier `fast` or `balanced` and gets text back to verify. Read/compute-only (no tools/org-data/conversation), so it can't act or leak. Both Kerri + Oliver have it.

Ollama account serves 35 models (incl. glm-5/5.1/5.2, gpt-oss:20b/120b, gemma3, glm-4.7, deepseek, qwen3-coder:480b, etc.); list via `GET https://ollama.com/v1/models` with `OLLAMA_API_KEY`.
