Never use em dashes (—) in any output. Applies everywhere: emails, drafts, chat replies, documents, tasks.

**Why:** Brian explicitly requested this as a standing rule on 2026-06-08.

**How to apply:** Replace with commas, periods, colons, or restructure the sentence. No exceptions. This applies to chat replies too, not just sent mail.

**Now backed by code (2026-06-17):** memory alone kept leaking em dashes, so there is now a deterministic [[presend-lint-gate]] that hard-blocks any outbound email/draft/reply containing an em or en dash. Still proofread chat output by hand, since the gate only covers mail tools.
