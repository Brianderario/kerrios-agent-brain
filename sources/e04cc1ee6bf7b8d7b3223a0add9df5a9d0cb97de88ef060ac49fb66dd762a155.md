HARD RULE (Brian, 2026-06-17): in any multi-tier sponsor package quote, the largest package is the most expensive AND carries the best (largest) discount, and the discount percentage must shrink at every step down the ladder.

**Why:** if a lower tier has a better discount than the top tier, you remove the incentive to buy up. The biggest package has to be the best deal.

**How to apply:** discount % = (rate card value − price) / rate card. With prices fixed (e.g. $75K / $50K / $25K), give the top tier the highest rate-card-to-price ratio and step the ratio down each tier. **To widen the top tier's discount, ADD product to it** (more placements, an extra content piece, an added vertical) so its rate-card value rises — never fix the order by shrinking a lower tier's discount or cutting the top price. Worked example, Xometry H0033: A $75K/$100K = 25% off, B $50K/$62K = 19.4%, C $25K/$30K = 16.7%. Codified in `brain/wiki/workflows/hwfyi-package-quote-playbook.md`.
