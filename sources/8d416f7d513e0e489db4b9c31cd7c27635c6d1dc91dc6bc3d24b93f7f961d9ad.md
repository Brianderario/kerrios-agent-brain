Kerri (the Savant agent in kerrihq-rails) has three document-generation tools, added 2026-07-06 (PR #445, squash `fa9c147`; MERGED + DEPLOYED to prod, both Render services live; migration ran via preDeploy db:prepare):

- **create_pdf_document** — agent passes body HTML → print-styled PDF via headless Chrome (Ferrum, same engine as signed contracts). `DocumentGeneration::PdfBuilder` + `DocumentGeneration::Chrome`.
- **create_word_document** — agent passes `blocks` (heading/paragraph/bullets/table) → real .docx built as minimal Office Open XML with rubyzip (NO gem; deliberately avoided the unmaintained caracal). `DocumentGeneration::DocxBuilder`.
- **create_excel_spreadsheet** — agent passes `sheets` (headers+rows) → real .xlsx via the **caxlsx** gem (new dep, pure Ruby). Numbers stay numeric. `DocumentGeneration::XlsxBuilder`.

Each tool's Tools schema carries the how-to-use "training" (structure, examples, gotchas). Registered in `TOOL_DISPATCH` + `Tools.definitions` (available to all installs — Kerri/Oliver/Vaughn). System prompt `action_capability_line` says which format to pick.

**Storage/delivery:** `GeneratedDocument` model stores bytes in a Postgres `file_data` column (durable across Render deploys — same pattern as sponsor_assets, NOT ActiveStorage disk which is ephemeral on Render). Served by `GeneratedDocumentsController#download` (login-gated, scoped to the user's own orgs; non-member → 404). Tools return an absolute `download_url` built from `APP_HOST`.
