Kerri's `search_mail` (kerrihq-rails) was structurally blind to archived mail until 2026-07-02: the Graph client always scoped `$search` to `/mailFolders/inbox/messages` (no all-mail option existed) and the Gmail client appended `in:inbox` to every query. Brian archives handled threads, so the agent kept failing to find exactly the mail he'd already touched (June "Hardware FYI x Freeform" chain in brian@hardwarefyi.com Archive; Cucina Venti + Alexander's Steakhouse threads archived in brian@kerrihq.com).

Fix (PR #316): query searches default to `folder: "all"` — Graph searches the mailbox root `/messages` (covers inbox/archive/sent/subfolders), Gmail drops the `in:inbox` scope and supports `in:archive`. No-query listings stay inbox-scoped for triage. Tool schema updated so the model knows.

**Why:** any future "Kerri can't find an email Brian sees" report should first check folder scoping, not query phrasing. Her self-saved "search all mailboxes" rule does NOT fix this class of miss — four inbox-only searches still miss archived mail.

**How to apply:** when debugging agent mail-search misses, reproduce with the same folder scope the tool uses (see [[savant-queue-badge]] pattern of checking the failing layer directly).
