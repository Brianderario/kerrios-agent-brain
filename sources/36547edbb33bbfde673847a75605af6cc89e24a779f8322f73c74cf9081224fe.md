**kerrihq.com** = the company marketing site. Single static file `index.html` at `~/Projects/kerrihq-website/` (no build step, no git). Hosted on **Cloudflare Pages**, project `kerrihq`, account `08aeb0afdf0f8d02729afb22f9023443` (brian@kerrihq.com). Production branch is **main**; wrangler is authed locally.

**Deploy to production (live domain):**
```
cd ~/Projects/kerrihq-website && mkdir -p dist
cp index.html favicon.ico favicon-16.png favicon-32.png favicon-180.png icon.svg og-image.png dist/
wrangler pages deploy dist --project-name=kerrihq --branch=main --commit-dirty=true
```
Deploy a clean `dist/` (only public files) so backups/configs do not leak. Custom domain kerrihq.com tracks the production (main) deployment, so this goes live immediately.
