2026-06-24 (interactive, Brian) — **per-user LIGHT MODE shipped to prod** ([kerrihq-rails#136](https://github.com/kerrihq/kerrihq-rails/pull/136), squash `943a917`):
- Sun/moon toggle in the sidebar footer; dark (Monaco) stays the default for everyone, choice persists on `users.theme` (default `"dark"`), server-renders the `<html>` class so there's no first-paint flash. Benji pre-set to light via a one-time migration.
- Mechanism (the non-obvious part): the Monaco neutral+status tokens (`ink/line/fg/ok/warn/err`) in `tailwind.config.js` now resolve to CSS variables `rgb(var(--c-*) / <alpha-value>)`; `:root` holds the dark values (exact RGB of the old hexes → dark is byte-identical) and `html.light` overrides for light, both defined at the top of `application.tailwind.css`. So re-theming is "redefine the variables," not edit every view. Brand tokens (`accent`, `magenta`, `prop`) stay theme-independent. Charts (`chart_controller.js`) carry their own dark/light color map + re-render on a `theme:changed` event. Legacy Railsblocks form widgets were already light-first so they adapt for free.
