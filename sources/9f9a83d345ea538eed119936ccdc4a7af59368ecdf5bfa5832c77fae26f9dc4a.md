Never send an email signed "Brian" from kerri@hardwarefyi.com (or any non-Brian mailbox). Signature and sending mailbox must always match: Brian-signed mail sends from brian@'s own mailbox; kerri@ mail is signed Kerri.

**Why:** Brian stopped a 44-email dinner-invite batch on 2026-06-11 that I had drafted Brian-signed from kerri@ (copying the June 8 first-round pattern, which was itself a violation). It misrepresents the sender, and recipients notice (a May invitee replied "Is this a bot?"). This is a hard rule, same family as [[feedback_post_call_followups]] (post-call follow-ups send from Brian, signed Brian, never Kerri).

**How to apply:** Before any send, check the signature line against the sending mailbox. If a draft is in Brian's voice/signature, route it through brian@hardwarefyi.com (his MCP or his mailbox). If sending from kerri@, sign as Kerri. When continuing an old thread that was itself mis-sent, fix the pattern going forward rather than copying it.
